# 产品功能对齐矩阵

本文档以本机安装的“超级右键 2.4.7”实际设置界面和 Finder 菜单为行为基线，仅记录可观察的产品能力；灵犀右键保持独立代码、视觉和素材。

状态说明：`已完成` 表示已有实现和验证；`部分完成` 表示能力存在但配置或边界不完整；`待实现` 表示尚无等价能力；`不复刻商业壳` 表示不复制评分、订购、推广和品牌素材。
